# Lộ trình TOEIC SW 30 ngày

Lộ trình 30 ngày ôn TOEIC Speaking & Writing từ mất gốc lên 220+, mỗi ngày 3 giờ (sáng 1h, tối 2h).

Trang web gồm: checklist nhiệm vụ từng ngày, từ vựng theo chủ đề, mẫu câu dùng chung, ngữ pháp, thông tin đề thi và sổ lỗi.

## Lưu tiến độ

- Mỗi lần tick ô, đánh dấu từ vựng hay thêm lỗi, tiến độ được lưu ngay vào trình duyệt (`localStorage`). Tải lại trang hay tắt máy vẫn còn.
- Dữ liệu nằm riêng trong trình duyệt của bạn, không gửi lên server. Xoá dữ liệu trình duyệt hoặc mở tab ẩn danh sẽ không thấy tiến độ.
- Để chuyển sang máy hoặc trình duyệt khác: bấm **Sao lưu** để tải file `.json`, rồi trên máy mới bấm **Khôi phục** và chọn file đó.

## Chạy local

Mở thẳng `index.html` bằng trình duyệt, không cần cài đặt gì.
